# Solar Field

Интерактивный планировщик солнечных панелей для плоской крыши частного дома:
20 × TOPCon bifacial 580 Вт, 2 × Deye SUN-6K-SG05LP1-EU, 2 × LiFePO4 15,36 кВт·ч.

**[Открыть планировщик →](https://babinslava.github.io/solar-field/)**

- 19 вариантов раскладки (вкладки, глубокие ссылки вида `#v-P`), целевой — **P**: 8 «стоя» 35° с вылетом на парапет + ряд «лёжа» 35° + два ряда 10° ЮВ = 20 панелей, ≈14,0 МВт·ч/год, без захода на крышу соседа.
- Панели и трубы перетаскиваются (shift+клик — группа), рулетка 📏, живой пересчёт выработки.
- Разделы: однолинейная схема электрики, помесячный баланс, net billing / zero-export, конструкция рамы, чек-лист замеров.

Все размеры и позиции труб — по рукописному эскизу, перед заказом конструкций сверить рулеткой по месту.
